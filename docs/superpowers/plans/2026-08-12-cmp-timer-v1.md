# CMP Timer v1 Implementation Plan

**Reviewed:** 2026-08-23
**Goal:** Add monotonic relative and absolute timer awaits to the existing Scheduler without a
background thread, new dependency, cancellation model, or detached ownership.
**Design:** `docs/superpowers/specs/2026-08-12-cmp-timer-v1-design.md`
**Toolchain:** C++23 Modules, mcpp and xlings 2026.8.11.2, LLVM 22.1.8,
compat.gtest 1.15.2.

The design records `feature/timer-v1` as the working branch. Do not run any Git or GitHub command,
including read-only status/diff commands, unless the user explicitly authorizes it for that task.
Commit, push, PR, and merge permissions remain independent.

## Tasks

- [x] Add focused failing tests for relative/absolute lower-bound behavior; asynchronous zero,
  negative, and past deadlines; overflow without wraparound; RunLoop-thread affinity; cross-thread
  registration of a new earliest timer; multiple/equal deadlines; invalid Scheduler use; pending
  timer cleanup and reuse; and repeated immediate timers.
- [x] Add the minimal timer state to `RunLoopState`: a steady-clock `std::priority_queue`, an

  elapsed deadlines, new-minimum notification, and cleanup in both normal and abort paths.
- [x] Update `RunLoopState::drive()` to check root completion first, promote at most one expired
  timer to the back of the FIFO per pass, resume outside the mutex, and use a non-predicate timed
  wait for the current earliest deadline.
- [x] Add two private timed awaiters and public Scheduler aliases plus `schedule_after()` and
  `schedule_at()`. Both awaiters always suspend and lock/validate the Scheduler state in
  `await_suspend()`.
- [x] Update the standalone example to await a short timer before printing from inside the
  coroutine.
- [x] After behavior passes, update the English, Simplified Chinese, and Traditional Chinese
  README and architecture documents so all three describe the same implemented contract.
- [x] Run Dev and Release verification, repeat the focused RunLoop tests enough to exercise the
  cross-thread wake path, and leave the working state ready for user review without staging,
  committing, pushing, or opening a PR.

## Test Discipline

- Use `steady_clock` for all observations.
- Duration semantics assert only that a continuation did not resume before its deadline.
- The new-earliest wake regression may use a generous upper completion timeout as a liveness
  check, not as a timer-precision guarantee.
- Give that regression a finite later deadline and deterministic thread joining so its failure
  cannot hang the test binary.
- Equal deadlines assert exactly-once completion, not ordering.
- Do not add a fake clock, public test hook, new dependency, or cancellation scaffold.
